# AI Graph

AI Graph looks for semantic relationships that are not yet explicit links. It can suggest connections, bridges, clusters, and idea islands from the language already in your vault.


## Why it exists

Some useful relationships are discovered after writing, not before it. AI Graph helps surface candidates; you decide which ones belong.

## When to use it

Use AI Graph after you have enough notes for patterns to emerge, when research crosses topics, or when the regular graph has separate islands.

## Workflow

Write notes → create a Space or index the vault → inspect suggestions → read both notes → add a real link only when the relationship is useful.

## Example review

- Suggested: `Attention` ↔ `Interface principles`
- Read both notes.
- Add a link from `Attention.md` to `Interface principles.md` only if it explains the connection.

> **OpenOnyx tip**
> Treat a suggestion as a reading prompt. The value is the judgment you make after opening the notes.

> **OpenOnyx common mistake**
> Do not accept suggestions in bulk. Similar wording is not the same as a meaningful relationship.
