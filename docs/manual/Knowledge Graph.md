# Knowledge Graph

The Knowledge Graph maps links you created between notes. It shows the visible shape of your vault: clusters, bridges, and notes that still have no connection.


## Why it exists

Links are easy to write and hard to hold in your head. A graph makes the structure available at a glance.

## When to use it

Use the graph when a project has grown beyond a few notes, when you want to find isolated ideas, or when you need a different route through familiar material.

## Workflow

Write a note → add a meaningful link → open graph → focus a cluster → return to the note that can strengthen the connection.

## Example

```md
Attention.md → Tools.md → Habits.md
```

The graph turns these three links into a path you can inspect and extend.

> **OpenOnyx tip**
> Look for bridge notes. They often hold the explanation that connects two projects or fields.

> **OpenOnyx common mistake**
> A dense graph is not automatically useful. Create links because they explain a relationship, not because density looks impressive.
