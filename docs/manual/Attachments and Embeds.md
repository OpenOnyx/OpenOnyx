# Attachments and Embeds

Attachments are files stored in the vault and referenced from notes. Embeds display another note, image, or supported file inside the current note.

## Attachments

Use attachments for images, PDFs, diagrams, exports, or source files that belong with the vault. Store them in a predictable folder if the vault will grow.

Example:

```text
Attachments/
  diagrams/
  screenshots/
  references/
```

## Images

Images can be inserted with normal Markdown image syntax. Keep the attachment path relative to the note or to the vault convention you use.

Use descriptive alt text so the note remains understandable even when the image is not visible.

## Embeds

Embeds use an exclamation mark before a vault link:

Embed when the content should be read in place. Link when the reader should intentionally navigate away.

## External media

External URLs and iframes should be used with care. They can disappear, change content, or load third-party resources. For durable reference material, save a local note that summarizes the source and links to it.
