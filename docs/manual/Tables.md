# Tables

Tables organize repeated fields. They are best for comparison, inventory, small checklists, and structured reference material.

## Basic syntax

```md
| Field | Meaning |
| --- | --- |
| status | Current workflow state |
| owner | Person responsible |
| reviewed | Last review date |
```

The editor can help insert or format tables, but the saved note remains Markdown.

## When to use a table

Use a table when rows share the same columns. Use headings or lists when each item needs a different amount of explanation.

Good table uses:

- Feature comparison.
- Plugin evaluation.
- Project inventory.
- Troubleshooting checklist.
- Settings reference.

## Keep tables readable

Markdown tables become hard to edit when cells contain long paragraphs. If a cell needs several sentences, link to a note or use a section instead.
