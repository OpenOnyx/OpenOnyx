# Quick Switcher

Quick switcher opens notes without navigating the folder tree. It is for movement by memory: title, phrase, abbreviation, or rough spelling.

## When to use it

Use quick switcher when you know the note exists or when the title is faster than the path. Use full vault search when you remember a phrase inside a note but not the title.

## Typical workflow

1. Open quick switcher.
2. Type part of a title.
3. Select the result.
4. Keep writing or follow links from the opened note.

## Create versus open

Depending on the command and current app behavior, entering a name that does not exist may create a note or prepare one. Before creating many notes this way, decide whether they belong in the root or a folder.

## Naming notes for switching

Quick switcher rewards clear titles:

- `Project Alpha Decision Log`
- `Meeting Notes 2026-09-26`
- `API Design Principles`
- `Attention as Interface Material`

Avoid vague titles like `Notes`, `Ideas`, or `Untitled 2` unless they are temporary inbox material.
