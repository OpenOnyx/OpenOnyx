# AI Writing Tools

AI writing tools help transform selected text, draft alternatives, and ask focused questions while you stay inside the note. They are assistants for revision, not a replacement for the source material in your vault.

## Typical uses

Use AI writing tools for:

- Summarizing a long selection.
- Rewriting a rough paragraph for clarity.
- Extracting action items.
- Turning notes into an outline.
- Asking a question about selected text.
- Finding missing assumptions before publishing a note.

## Selection-based workflow

1. Select the smallest useful text.
2. Choose the writing action.
3. Read the result before accepting it.
4. Keep citations, links, or original context when the claim matters.
5. Edit the final text in your own voice.

## Privacy boundary

AI behavior depends on the configured provider and model. Local vault features can work without an account, but external AI calls may send selected text or retrieved context to a provider you configure. Review settings before using AI on sensitive notes.

## Good prompts

Specific prompts work better than broad prompts:

```text
Rewrite this as a decision record with context, decision, consequences, and open questions.
```

```text
Extract only the unresolved action items and keep the original names.
```
