# Markdown

Markdown is the file format beneath OpenOnyx. You can read it in any text editor, track it with Git, and keep using it if you leave the app.


## Why it exists

Your knowledge should not depend on a proprietary file format. Markdown preserves the words, headings, links, lists, and code that make a note useful.

## When to use it

Use Markdown for all ordinary notes. Use `.canvas` when spatial arrangement is the thing you are trying to think through.

## Workflow

Write Markdown → preview it live → add a Markdown link → inspect backlinks → search or graph the vault.

## Example

```md
# Project decision

- [x] Compare the two approaches
- [ ] Write the implementation note

See the architecture note for the constraints.
```

> **OpenOnyx tip**
> Prefer headings that state an idea. `# Why cache invalidation is hard` is easier to find than `# Notes`.

> **OpenOnyx common mistake**
> Do not rely on visual formatting alone. Use headings and links so the note stays useful in every Markdown reader.
