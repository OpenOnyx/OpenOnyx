# Open a Vault

A vault is an ordinary folder that OpenOnyx can read and write. It can contain Markdown, Canvas files, attachments, and your existing project structure.


## Why it exists

Folders are understandable everywhere. They keep your knowledge visible to version control, backup tools, file managers, and other Markdown apps.

## When to use it

Open a vault when you are ready to work with a project, a personal knowledge base, meeting notes, or an existing Obsidian folder.

## Workflow

Choose folder → inspect files in the sidebar → open or create a note → link related notes → revisit through search or graph.

## Recommended structure

```text
My Vault/
├── Inbox/
├── Projects/
├── Areas/
├── Resources/
└── Archive/
```

Structure is optional. OpenOnyx also works well with a flat folder and strong links.

> **OpenOnyx tip**
> Use folders for broad context and links for meaning. A note can belong to more than one idea without being duplicated.

> **OpenOnyx common mistake**
> Avoid opening a system folder or a large dependency directory. Start with a folder created for notes.
