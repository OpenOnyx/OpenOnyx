# Outgoing Links

Outgoing links show where the current note points. They help you audit the note's claims, references, and dependencies.

## Why outgoing links matter

A note can look complete while depending on missing or weak references. Outgoing links reveal whether the note points to the right source material.

Use the outgoing links panel to answer:

- Which notes does this note depend on?
- Are any links broken or misspelled?
- Does this note point to too many unrelated places?
- Should a link become a clearer sentence?

## Link review workflow

1. Open the note.
2. Read each outgoing link in context.
3. Open important linked notes.
4. Remove decorative links that do not help comprehension.
5. Add missing links where the note makes a claim already covered elsewhere.

## Broken or missing links

If a linked note does not exist, decide whether to create it or remove the link. A missing note can be a useful placeholder, but too many placeholders make the vault feel more connected than it is.
