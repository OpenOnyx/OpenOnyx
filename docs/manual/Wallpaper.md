# Wallpaper

Vault wallpaper adds a background image behind the workspace with blur and opacity controls. It changes atmosphere while leaving the writing surface usable.


## Why it exists

A workspace can feel personal without turning content into decoration. Wallpaper gives a vault a recognizable place while preserving the notes as the focus.

## When to use it

Use wallpaper for a project vault, a shared space, or a personal workspace where subtle place cues help you return to the work.

## Workflow

Choose image → set opacity and blur → open a long note → adjust until text remains effortless to read.

## Example settings

```text
Opacity: low
Blur: medium
Text contrast: unchanged
```

> **OpenOnyx tip**
> Use quiet images with broad shapes. The best wallpaper is noticeable when you arrive and invisible while you write.

> **OpenOnyx common mistake**
> Avoid high-contrast images behind dense text or graph views.
