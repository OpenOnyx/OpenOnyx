# Editor Toolbar

The editor toolbar provides visible controls for common formatting and insertion actions. It is useful when you do not remember Markdown syntax or when a touchpad workflow is faster than a keyboard shortcut.

## Formatting controls

Use the toolbar for inline and block formatting:

- Bold, italic, strikethrough, and code.
- Headings and paragraph formatting.
- Bullet, numbered, and task lists.
- Blockquotes and callouts.
- Links, embeds, images, and tables.

The toolbar writes Markdown into the note. It does not create hidden rich-text state.

## Selection behavior

When text is selected, formatting commands usually wrap the selection. When no text is selected, commands insert syntax at the cursor or prepare a block for typing.

Examples:

```md
**selected text**
_selected text_
`selected text`
```

## Insert actions

Insert actions are for content that has structure:

- Insert a table when information belongs in rows and columns.
- Insert a callout when a warning, note, or tip should stand apart.
- Insert an image when visual material is part of the source note.
- Insert a link when the destination matters to the argument.

## Best practice

Use the toolbar to learn the Markdown shape, then edit the text directly when you need precision. Markdown remains the durable record.
