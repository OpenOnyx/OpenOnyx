# Bookmarks

Bookmarks save important places so you can return without searching. They are useful for index notes, project dashboards, active canvases, frequent searches, and review queues.

## What to bookmark

Bookmark stable entry points:

- Home note or vault index.
- Current project plan.
- Decision log.
- Inbox.
- Frequently used canvas.
- Search query for unresolved work.

Do not bookmark every interesting note. Bookmarks work best as a small navigation layer.

## Review bookmarks

Outdated bookmarks are navigation debt. Review them when a project ends or when the sidebar feels noisy.

## Bookmarks versus pinned tabs

Use a bookmark for something you want to return to across sessions. Use a tab for something needed in the current session. Use a split pane for something that must stay visible beside current work.
