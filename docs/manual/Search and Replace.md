# Search and Replace

Search and replace works inside the current note. It is different from full vault search: it changes local text in one file instead of finding material across the vault.

## Use local find

Use find when the note is long and you need a heading, phrase, link, tag, or repeated term. This is usually safer than scrolling because it lands on exact text.

## Use replace carefully

Replace is useful for repeated wording changes, renamed terms, or cleanup after pasted text. Before replacing many matches, check the first few results to confirm they mean the same thing.

Good replacement candidates:

- A misspelled project name.
- A repeated formatting marker.
- A changed term inside one note.

Risky replacement candidates:

- Common words.
- Link targets that may appear in prose.
- Terms with several meanings.

## Vault-wide changes

For changes across many files, use rename operations or controlled search workflows rather than blindly editing files. Back up first if the operation affects many notes.
