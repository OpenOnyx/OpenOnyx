# Right Sidebar

The right sidebar holds contextual panels for the active note. It is where OpenOnyx puts supporting information that is useful while writing but should not interrupt the note itself.

## Common panels

Depending on the enabled features and plugins, the right sidebar can include:

- Backlinks.
- Outgoing links.
- Unlinked mentions.
- Outline.
- Properties.
- Tags and related metadata.
- Plugin panels.

These panels usually follow the active note. Click a note tab to make sure the sidebar is showing the context you intend to inspect.

## When to keep it open

Keep the right sidebar open when reviewing structure, links, references, or metadata. Collapse it when drafting prose and you need the editor to feel quiet.

Good uses:

- Editing an index note while watching backlinks.
- Reviewing a long note with the outline visible.
- Checking frontmatter before publishing or sharing.
- Following outgoing links from a decision record.

## Context discipline

The right sidebar is helpful because it reacts to the active note. That also means it can become distracting if you are switching quickly. For focused writing, choose one panel that supports the task and close the rest.
