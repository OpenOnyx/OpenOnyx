# Editor

The editor is where Markdown becomes daily work. OpenOnyx uses a CodeMirror-based editor with live formatting, source-friendly Markdown behavior, context menus, search, formatting commands, embeds, tables, comments, and optional inline AI tools.

## Editing modes

The editor is built for people who want readable Markdown while they write. Formatting can be inserted through keyboard shortcuts, context menus, toolbar controls, or direct Markdown syntax.

Use source-like editing when exact characters matter. Use preview-oriented reading when you are reviewing structure, links, and rendered content.

## Common editing actions

The editor supports the everyday Markdown operations you expect:

- Bold, italic, strikethrough, inline code, and code blocks.
- Headings from level 1 through level 6.
- Bullet, numbered, and task lists.
- Blockquotes and callouts.
- Markdown links, wiki links, and embeds.
- Tables and table editing helpers.
- Images and file attachments.
- Find and replace inside the current note.

## Context menu

Right-clicking in the editor exposes common writing commands. Depending on the selection and cursor location, you can format text, insert links, convert URLs, embed media, create a note from selected text, or search the vault for the selected phrase.

## Autosave and explicit save

OpenOnyx is designed around files on disk. Save regularly with the keyboard shortcut, especially before using plugins or bulk operations. If sync is enabled, saving also helps establish a clear local state before queued sync work.

## Working with selections

Selections can be formatted, linked, searched, extracted into a new note, or used as context for inline AI tools. For reliable notes, treat AI output as draft text and keep your source citations or reasoning nearby.
