# Sync

Sync is optional in OpenOnyx. Local writing works without a server. When you need shared access, you can connect your own Supabase project.


## Why it exists

Collaboration should extend ownership, not replace it. Your local vault remains the source material; sync is a choice you configure.

## When to use it

Use sync when a Space needs to move between machines or when a team needs a shared knowledge surface.

## Workflow

Keep a local vault → configure your Supabase project → choose what to sync → verify a second device → continue working offline when needed.

## Before you connect

- [ ] Back up the vault.
- [ ] Confirm who controls the Supabase project.
- [ ] Decide which notes belong in the shared Space.

> **OpenOnyx tip**
> Start with one small Space before connecting a whole archive.

> **OpenOnyx common mistake**
> Live multiplayer editing is currently under maintenance. Plan collaboration around the current status shown in the app.
