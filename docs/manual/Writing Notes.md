# Writing Notes

Writing is the center of OpenOnyx. Notes remain plain Markdown while the workspace adds source, preview, split view, links, backlinks, and tables around them.


## Why it exists

Thinking improves when writing stays easy to begin and easy to return to. Markdown keeps the text durable; OpenOnyx supplies context when you need it.

## When to use it

Use a note for an observation, a meeting, a decision, a question, or a working draft. Add structure only when the note earns it.

## Workflow

Capture an idea → name it clearly → add one link → review backlinks → use [Knowledge Graph](<Knowledge Graph.md>) or [Vault Intelligence](<Vault Intelligence.md>).

## Example

```md
# Attention is a design material

Tools change what becomes easy to notice.

Related: [Writing Notes](<Writing Notes.md>) and [Knowledge Graph](<Knowledge Graph.md>).
```

> **OpenOnyx tip**
> Write the useful sentence before organizing it. A note with a clear claim is easier to link than an empty category.

> **OpenOnyx common mistake**
> Do not use folders as a substitute for links. Folders answer where a file lives; links answer what it means.
