# Keyboard Shortcuts

Keyboard shortcuts keep attention on the note. Learn the few that move you between writing, finding, and connecting.


## Why it exists

Context switches are expensive. Shortcuts make frequent actions available without leaving the thought you are shaping.

## When to use it

Use shortcuts once an action becomes repetitive. Begin with opening notes, commands, graph, and save.

## Workflow

Open note → write → save → search or graph → return to the note.

## Core shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl/Cmd+N` | Create note |
| `Ctrl/Cmd+S` | Save note |
| `Ctrl/Cmd+O` | Quick switcher |
| `Ctrl/Cmd+P` | Command palette |
| `Ctrl/Cmd+G` | Open graph |
| `Ctrl/Cmd+Shift+C` | New canvas |

> **OpenOnyx tip**
> Learn one shortcut per workflow, not every shortcut at once.

> **OpenOnyx common mistake**
> Browser shortcuts and app shortcuts differ. This table describes the desktop app.
