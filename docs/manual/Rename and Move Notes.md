# Rename and Move Notes

Renaming and moving notes are normal parts of maintaining a vault. They are also real filesystem operations, so they deserve more care than changing a heading.

## Rename a note

Rename when the title no longer describes the note. A good title improves search, quick switcher, graph readability, and link clarity.

Before renaming a central note:

- Open backlinks.
- Check outgoing links.
- Confirm whether internal links should be updated.
- Consider whether aliases or a transition note are needed.

## Move a note

Move a note when its lifecycle or project context changed. Do not move a note just because it gained another relationship; add a link instead.

## Rename folders

Folder renames affect every path underneath the folder. Back up first if the folder contains many notes, attachments, or canvas boards.

## Link updating

When automatic internal link updating is enabled, OpenOnyx can rewrite links after a rename or move. Review the changed notes if the rename is broad or ambiguous.
