# Callouts

Callouts make a block of text visually distinct while keeping it in Markdown. Use them for notes, warnings, questions, summaries, and action items that should stand apart from the main flow.

## Basic syntax

```md
> [!note]
> This is a note callout.

> [!warning]
> Review this before changing the vault structure.
```

OpenOnyx renders common callout types in preview and preserves the underlying Markdown.

## Good uses

Use callouts for:

- Important constraints.
- Warnings before destructive work.
- Temporary questions.
- Decision summaries.
- Examples that interrupt the main narrative.

## Avoid overuse

If every paragraph is a callout, none of them stand out. Convert repeated callouts into headings or sections once the note matures.

## Callouts and portability

Callout syntax is readable as a blockquote in plain Markdown tools. That means the content remains available even when a reader does not support callout styling.
