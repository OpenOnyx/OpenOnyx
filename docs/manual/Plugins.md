# Plugins

OpenOnyx includes an Obsidian-compatible plugin runtime so a vault can grow without giving up its file-first foundation.


## Why it exists

Every workflow has edges. Plugins let you add specialized tools while keeping notes as the common format beneath them.

## When to use it

Use plugins after the core editor, links, search, graph, and Canvas are already working for you. Add one when it removes repeated work.

## Workflow

Identify a repeated task → evaluate one plugin → review its permissions → test it in a copy of the vault → keep it only if it improves the workflow.

## Example checklist

- [ ] I know the task this plugin removes.
- [ ] I reviewed its permissions.
- [ ] I can still read my vault without it.

> **OpenOnyx tip**
> Prefer plugins that enhance a file you already understand over plugins that create a private system you cannot inspect.

> **OpenOnyx common mistake**
> Do not install a plugin just because it is popular. Every plugin becomes part of the workspace you maintain.
