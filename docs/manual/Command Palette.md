# Command Palette

The command palette is the fastest way to find actions without remembering where they live. It searches app commands, plugin commands, and workflow actions by name.

## Open the command palette

Use the keyboard shortcut from [Keyboard Shortcuts](<Keyboard Shortcuts.md>) or open it from the interface. Type a few words from the action you want.

Examples:

```text
graph
toggle sidebar
new canvas
settings
```

## How commands are useful

Commands are especially helpful for actions that are important but not constant:

- Toggle sidebars.
- Open graph views.
- Create a canvas.
- Navigate to settings.
- Run plugin actions.
- Trigger search or quick switcher.

## Plugin commands

Plugins can add commands. If a plugin is enabled but its command does not appear, confirm the plugin loaded successfully and has the permissions it needs.

## Command naming

Search by verbs. If you do not remember the exact command, try words such as `open`, `toggle`, `create`, `search`, `graph`, or `sync`.
