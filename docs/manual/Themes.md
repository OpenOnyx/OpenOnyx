# Themes

Themes change the workspace surface without changing the vault. OpenOnyx includes dark, light, oceanic, and custom theme support.


## Why it exists

You spend long sessions with your notes. A readable, comfortable surface helps you stay with the work.

## When to use it

Use themes to improve contrast, reduce distraction, or align the workspace with the environment where you think best.

## Workflow

Choose a theme → write for a real session → check code, links, and selections → keep the one that makes reading easier.

## Example

| Need | Starting point |
| --- | --- |
| Low-light writing | Dark |
| Long reading session | Light |
| Personal environment | Custom theme or [Wallpaper](<Wallpaper.md>) |

> **OpenOnyx tip**
> Judge a theme with your longest notes, not its settings preview.

> **OpenOnyx common mistake**
> Do not sacrifice contrast for mood. Links, selections, and code need to remain legible.
