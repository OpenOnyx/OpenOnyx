# Knowledge starts with a folder

OpenOnyx is a local-first knowledge platform. Your vault is a folder. Your notes are Markdown files. The editor, Knowledge Graph, AI Graph, and Vault Intelligence all work from that same source.


## Why it exists

Ideas outlive tools. A folder of readable files lets you change tools without abandoning your work.

## When to use it

Use OpenOnyx when you want one place to write, connect, search, and revisit knowledge without giving up ownership of the files.

## Workflow

1. [Install OpenOnyx](<Installation.md>).
2. [Open a folder as a vault](<Open a Vault.md>).
3. [Write a note](<Writing Notes.md>) and connect it with a descriptive Markdown link.
4. Use [Knowledge Graph](<Knowledge Graph.md>) to see explicit links.
5. Use [Vault Intelligence](<Vault Intelligence.md>) and [AI Graph](<AI Graph.md>) when you want help finding context.

> **OpenOnyx tip**
> Start with a folder you already trust. A small vault with useful notes teaches more than an empty taxonomy.

> **OpenOnyx common mistake**
> Do not treat OpenOnyx as the only copy of your knowledge. Your vault is already portable; back it up like any other important folder.
