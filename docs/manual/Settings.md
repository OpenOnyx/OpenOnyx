# Settings

Settings control how OpenOnyx behaves across editing, appearance, AI, plugins, sync, vault handling, and compatibility. Change settings deliberately and test them against a real note.

## Main setting areas

OpenOnyx settings commonly affect:

- Appearance, themes, and wallpaper.
- Editor behavior and typography.
- Link style and link updating.
- AI provider configuration.
- Spaces and vault intelligence.
- Plugin installation and permissions.
- Sync configuration.
- Vault startup behavior.

## Change settings safely

For visual settings, open a long note, a code block, a link-heavy note, and a graph view before deciding. For vault or plugin settings, test in a copy if the setting can rename, move, or rewrite files.

## AI settings

AI settings may include model, API key, provider, and behavior controls. Treat API keys as secrets. Do not paste them into notes, screenshots, issues, or shared vault files.

## Plugin settings

Plugin settings belong to the plugin that created them. If a plugin behaves unexpectedly, disable it, reopen the vault, and then re-enable it after checking permissions.

## Resetting a bad configuration

If a setting makes the interface hard to use, return to a built-in theme, disable wallpaper, collapse plugin panels, and restart the app. For plugin issues, disable the plugin before changing unrelated app settings.
