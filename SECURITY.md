# Security Policy

## Supported Versions

We maintain and release security updates for the latest major version of OpenOnyx.

| Version | Supported |
| :--- | :---: |
| 1.x (Latest) | Yes |
| < 1.0 | No |

---

## Reporting a Vulnerability

The OpenOnyx maintainers take security seriously. If you believe you have discovered a security vulnerability in OpenOnyx, please report it privately so we can fix it before public disclosure.

### How to Report

Please do **NOT** report security vulnerabilities through public GitHub issues or public discussions.

Instead, contact any maintainer privately.
   

### What to Include in Your Report

To help us investigate and resolve the issue quickly, please include:
- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions to reproduce the issue (including any sample Markdown files, payloads, or setup steps).
- The operating system and version of OpenOnyx where the issue was observed.
- Any suggested mitigations or patches if available.

### Disclosure Policy

- We will acknowledge receipt of your report within **48 hours**.
- We will provide an estimated timeline for addressing the issue and keep you updated on progress.
- Once a fix has been verified and released, we will publicly acknowledge your responsible disclosure (unless you prefer to remain anonymous).
